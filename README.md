# Learning Transformer Architecture

An interactive slide deck that explains the Transformer from **"Attention Is All You Need"**, with diagrams, Python code for each concept, and quizzes.

**Live deck:** [saurabhkaushik120692.github.io/learning-transformer-architecture](https://saurabhkaushik120692.github.io/learning-transformer-architecture/)

## Topics

- Why Transformers replaced RNNs and LSTMs
- Tokens, embeddings and positional encoding
- Self-attention, Q / K / V and scaled dot-product attention
- Multi-head attention
- Residual connections, LayerNorm and the feed-forward network
- The decoder: masked attention, cross-attention, KV cache
- Encoder-only vs decoder-only models

## Controls

| Key | Action |
|---|---|
| `←` `→` | Previous / next |
| `G` | All slides |
| `C` | Python code for the slide |
| `H` / `P` | Highlighter / pointer |
| `T` | Light / dark theme |
| `F` | Fullscreen |

## Run locally

Open `index.html` in a browser. No build step.
